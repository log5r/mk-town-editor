# MKTownEditor

MKTownEditor は、macOS の標準コンポーネントで構成した書類ベースの Markdown エディタです。CodiMD の編集・プレビュー体験を参考にしながら、ローカルファイルを扱うネイティブアプリとして設計しています。

## 主な機能

- `.md` / プレーンテキストファイルの読み込みと `.md` への保存
- 編集、左右分割、プレビューの3つの表示モード
- 設定でインラインライブ表示を有効化すると、編集中以外のMarkdown記号を控えめな色で表示。原文・コピー・Undoは維持
- タイプライターモードで入力行を画面中央付近に配置。手動スクロール後とIME変換中は自動追従を抑制
- ローカル用語辞書で避ける表記と推奨表記を登録し、コード・引用を除外して確認。結果から原文へ移動、またはUndo可能な置換
- ワークスペース内の本文・フロントマターからタグを集め、タグ別に文書を絞り込んで開く。開いている文書の未保存本文も反映
- インスペクタから単一行のフロントマタープロパティを追加・変更・削除。未知のキー、ネストした値、コメントを保持してUndo可能
- インスペクタのバックリンク一覧で、現在の文書への参照元・抜粋を確認し、リンクがある原文位置へ移動。未保存本文を反映
- インスペクタから `[[文書名]]` のWikiリンクを検索・補完して挿入。リンク先を開く、標準Markdownリンクへ変換、ファイル改名・移動時の参照更新に対応
- 単独行の `![[文書名]]` / `![[文書名#見出し]]` をプレビューに埋め込み。保存済み・編集中の参照先を更新し、循環参照と過深な展開を止める
- ファイルサイドバーから日付ノートを作成・再オープン。`Daily/YYYY-MM-DD.md` に日記・会議メモ・空白のテンプレートを選べる
- ファイルサイドバーからワークスペース全体の未完了タスクを一覧表示。元の書類を開くか、原文の行を照合してUndo可能な編集で完了にする
- インスペクタから文書間リンクのグラフを表示。現在の書類の近傍を表示し、必要な時は全体表示へ切り替えられる
- インスペクタから現在のセクションを別書類へ分割し、複数書類を新しい書類へ結合。見出し階層と相対リンク・画像パスを調整する
- インスペクタで開いている書類と表示・サイドバー・分割配置を名前付きレイアウトとして保存。復元時は既存ウインドウにも適用し、移動した書類のパスを追跡する
- 見出し階層を表示するアウトラインサイドバー。項目を選ぶと編集位置とプレビューの見出しへ移動
- 編集カーソルが属する見出しをアウトライン内で強調表示
- 「移動」メニューの指定行へ移動で行番号を入力可能。範囲外は先頭または末尾の行へ補正
- 見出し名を絞り込むクイック検索から目的の見出しへ移動
- ナビゲーションの「戻る／進む」。アウトライン・指定行・見出し検索による移動を履歴で辿れる
- `#見出し`形式の文書内リンクから、重複名を区別して該当見出しへ移動
- 相対パスの Markdown リンクから別の書類を開き、`#見出し`指定があれば開いた書類の見出しへ移動
- リンク編集で現在の書類フォルダ内のファイル・フォルダを候補表示し、相対パスを補完
- `#`入力時に現在またはリンク先 Markdown 書類の見出しを補完し、既存の参照IDから参照形式リンクを挿入
- 文字列を選択して Web URL またはメール URL を貼り付けるとリンクに変換。コンテキストメニューからそのままの貼り付けも可能
- ツールバーのリンク診断でローカルファイル・画像・見出し・参照定義の欠落を一覧にし、原文の該当位置へ移動
- リンク診断から外部URLの到達状態を手動で確認。認証が必要な応答、一時障害、欠落を区別
- 原文とプレビューのリンクにホバーすると、ローカルMarkdownの該当節を表示。外部ページの題名取得は設定で有効化
- 分割表示で原文とプレビューをブロック単位で双方向スクロール同期
- プレビューの段落・見出し・コードなどのコンテキストメニューから、対応する原文範囲を選択して表示
- 編集とプレビューの表示倍率を別々に保存し、表示倍率メニューとショートカットから拡大・縮小・リセット
- Swift、JavaScript／TypeScript、Python、JSON、シェルのコードブロックを基本的な字句で色分け
- 長文プレビューを可視ブロックから遅延描画し、変わらないブロックと表セルの描画属性を再利用
- 標準検索バーの置換・すべて置換・選択範囲内のすべて置換、次／前の検索へメニューとショートカットからアクセス
- 正規表現で検索・1件置換・すべて置換。選択範囲内の検索・置換、番号付きキャプチャ参照、無効なパターン、ゼロ幅一致に対応
- 表の選択セルを基準に、行や列を追加・削除し、列を左右・中央に配置。Markdownメニューから操作でき、Undoに対応
- 表のセルはTab／Shift-Tabで移動。最後のセルで行を追加するかどうかは設定で選択可能
- 表の列幅と区切り行を整形。日本語・エスケープしたパイプ・列配置を考慮
- クリップボードのTSV・CSVをMarkdown表に変換。セル内改行は確認後に`<br>`へ変換
- 表の選択行・列を隣へ移動し、選択列を基準にデータ行を昇順・降順にソート。ヘッダーを固定し、Undoに対応
- 既存の表をグリッド画面で編集。セル、行・列、配置を確定時に原文へ反映し、1回のUndoで戻せる
- 書き出しメニューからスタイルとローカル画像を同梱したHTMLを保存
- 同じHTML描画モデルからA4でページ分割したPDFを書き出し
- ページ設定と印刷パネルから印刷。余白、書類名ヘッダー、ページ番号フッターを指定可能
- 選択範囲をHTML・RTF・装飾記号のないテキストの3形式でコピー
- Markdown記号を除いたUTF-8テキストを書き出し。リンク先・画像説明・脚注の収録を選択可能
- HTML・PDF書き出しで本文幅、フォント、余白、表紙、目次を設定し、プリセットとして保存
- フォルダをワークスペースとして開き、サイドバーでMarkdown書類と添付を一覧・更新
- ワークスペース内のMarkdown書類をファイル名・相対パスの曖昧検索で開く
- ファイルツリーから書類・フォルダの作成、名前変更、移動、ゴミ箱への移動を実行。移動前にリンク更新を確認
- 新規書類は空白、はじめに、会議メモ、記事のテンプレートから選び、選択したフォルダに作成
- 文字コードを指定して既存ファイルをプレビューし、UTF-8・Shift JISなどへ損失を検査して変換保存
- UTF-8書類のLF・CRLF・CRとBOMを読み込み時に識別・保存時に保持。文字コードメニューから明示変換
- 書類ごとに選択位置、編集スクロール、分割比、サイドバーの表示状態を復元
- ワークスペース全体で本文を検索し、対象・除外パターンとファイル・行別の結果から該当箇所を開く
- 複数ファイルの一括置換は差分を確認して対象を選択。外部変更と開いている書類を検査し、途中失敗時は復元
- フォルダ検索・一括置換で見出し、本文、コードブロックへ検索範囲を絞り込み
- プレビュー表示中も検索・次・前のコマンドを使い、原文位置と対応するプレビューブロックへ移動
- 改名・移動時のリンク更新は開いている参照元の未保存本文も確認し、成功後に編集ウインドウへ反映
- 全文・選択範囲・現在セクションの文字数を確認。空白込み／除外の内訳も表示
- 語数を空白区切り・日本語・英語の単語分割から選択。数え方を統計ポップオーバーに表示
- 日本語・英語別の読む速度と音読速度を設定し、読了・音読時間の目安を表示
- 文書ごとの文字数目標とセッションの増減をローカル設定に保存
- Markdown診断で見出し階層、リンク先、箇条書き記号の揺れを確認し、規則を個別に無効化
- 文書全体または選択行のMarkdown自動整形を差分確認後に適用し、Undoで元に戻す
- スペルチェックの言語と自動訂正を設定し、コード・URL内では自動訂正を停止
- 裸URL、`www.`、メールアドレスをプレビューとHTMLで自動リンク化
- `[^id]`と`[^id]:`の脚注を参照順に採番し、一覧と本文への戻り操作を表示
- 先頭のYAMLフロントマターを本文から分離し、プレビューでの表示を切替
- GitHub形式のコールアウトを引用から識別し、種類ごとのアイコンとラベルを表示
- 脚注参照と定義を重複しないIDで一括挿入し、定義本文へ移動
- 選択範囲のインライン書式を除去。リンクは表示名とURL、画像は代替テキストとURLを残す
- 見出しからMarkdownの目次を生成。既存の目次を選択すれば選択範囲だけ更新可能
- 番号付きリストを同じ階層の連続項目ごとに再採番し、開始番号を維持
- 選択した行の複製・上下移動・削除。最終行に改行がない文書も操作可能
- 選択した文字列をHTMLコメントで囲み、コメント内から再実行すると解除
- 選択範囲をリンク・段落・リスト項目・セクションへ段階的に拡大し、前の範囲へ縮小
- 見出し配下とコードブロックを原文を変更せず折りたたみ。行番号欄に印を表示し、移動先が隠れていれば展開
- 設定で短縮語とテンプレートを登録し、Tabまたはメニューから挿入。`${1:文字}`形式の入力欄をTabで順に移動
- Command+Shift+Pでコマンドパレットを開き、操作名やショートカットから現在利用できる操作を検索・実行
- プレビューのリモート画像は設定で許可した場合だけ非同期読込。取得結果をメモリにキャッシュし、失敗時は代替テキストを表示
- プレビューの画像をクリックすると拡大表示。ローカル画像はQuick Look、許可したリモート画像はキャッシュから原寸表示でき、Escapeで元のプレビュー位置へ戻る
- 画像挿入時に表示幅を指定すると`![代替テキスト](画像){width=320}`を生成。画像だけの段落は代替テキストをキャプションとして表示し、HTMLにも書き出す
- ファイル画像の挿入時に派生画像を選ぶと、最大幅・高さ、PNG／JPEG／HEIC、画質を指定して`assets`へ保存。元ファイルは変更しない
- ワークスペースの添付確認で、欠落画像、未使用候補、参照されている添付を参照元の書類つきで一覧表示。未使用候補はFinderで確認できる
- リンク挿入画面からPDFなどのファイルを`assets`へコピー、または元ファイルを相対参照できる。プレビューのローカル添付リンクはQuick Lookで確認可能
- 選択したリンクをインライン形式と参照形式の間で変換。既存の定義を再利用し、共有定義は削除しない
- サイドバーで文書の任意位置をブックマーク。周辺本文と見出しを使って編集後の位置を探し、文書・フォルダ移動時も保存先に追従
- アウトラインの見出しからセクション全体を上下へ移動。子見出しと本文をまとめて扱い、Undoで元に戻せる
- アウトラインから見出しと子見出しをまとめて昇格・降格。H1〜H6の範囲外になる操作は実行しない
- インスペクタに現在の文書のタスク・リンク・画像を種別ごとに一覧表示し、選択すると原文へ移動
- 分割表示を左右・上下から選び、編集とプレビューの順序を入れ替え可能。仕切り位置と配置は書類ごとに保存
- 現在の書類のプレビューを別ウインドウで開き、編集内容を同じ書類モデルから表示。編集ウインドウを閉じるとプレビューも閉じる
- 保存済み書類の明示スナップショットに名前を付けて保存し、行単位で差分を確認して本文全体または変更箇所をUndo可能な編集として復元
- ワークスペースのフォルダごとにタブ・リスト・コードの字下げ幅、添付保存先（`assets`/`images`）、Markdown構文プロファイルを設定。未指定項目は親フォルダ・アプリ設定を継承
- 任意導入のPandocを指定してDOCX・ODT・EPUBへ書き出し。未導入・変換エラーを表示し、失敗や中止では既存の出力を保持
- HTML・RTFを選んでMarkdownへの変換結果と画像・装飾の警告を確認し、現在の書類へUndo可能な一回の編集として取り込む
- 保存済み書類と参照画像・添付をMarkdownまたはHTMLの持ち出し用フォルダ／ZIPへ書き出し。相対参照をパッケージ内へ更新し、欠落画像や既存の同名出力があれば中止
- 対象フォルダ内の複数書類をMarkdown・HTML・PDF・プレーンテキストへ一括書き出し。フォルダ構成と開いている書類の未保存本文を反映し、進捗・中止・文書ごとの失敗を表示。同名出力は上書きせずスキップ
- プレビューの本文最大幅と配色を設定可能。既定はシステム外観に追従し、紙色では見出し・コードを高コントラストの色で表示
- エディタで空白・タブ・改行・末尾空白とインデントガイドの表示を切り替え可能。本文やUndo履歴を変更しない
- Command+Shift+J で集中モードを切替。ツールバー、サイドバー、統計を一時的に隠し、終了時に以前の表示へ戻す
- macOS標準のツールバーカスタマイズで、書式・見出し・リスト・画像・表などの操作を追加・並べ替え可能
- 設定画面にコマンドのショートカット一覧と変更画面を用意。重複・macOS予約操作を防ぎ、メニューとコマンドパレットへ反映
- プレビューのコードブロックからコード本文だけをワンクリックでコピー
- プレビューの自動更新を一時停止し、表示世代と原文世代を確認しながら手動更新・再開。別ウインドウにも同じ状態を反映
- ワークスペースのファイル一覧でピン留め、名前順・更新日時順、書類・添付・拡張子のフィルターを保存
- 編集画面で見出し、リスト、引用、コード、リンク、表の記号を色分け
- 任意表示のミニマップで文書の行密度と現在の表示位置を確認し、クリック・ドラッグで移動
- ソース編集の行番号ガター。長い行の折り返しは同じ行番号として表示
- Return でリスト・タスクリスト・引用を継続し、空項目では階層を終了
- Tab／Shift-Tab またはメニューでリスト項目と子ブロックのインデントを変更
- 括弧、バッククォート、強調記号の対を入力時に補完し、選択文字列も囲める
- 入力と同時に更新されるネイティブ Markdown プレビュー
- `mermaid`言語のコードブロックをオフラインで図として表示。図と原文を切り替え、構文エラーの行番号を表示
- `dot`/`graphviz`と`plantuml`/`puml`のコードブロックを、設定で選んだGraphviz実行ファイルまたはPlantUML JARで描画（PlantUMLにはJavaが必要）。時間制限と中止、原文表示を用意
- 同じフォルダの`references.bib`を読み、拡張構文の`[@キー]`を番号付き引用と参考文献一覧に変換。プレビュー・HTML・PDF・DOCX/ODT/EPUBで同じ番号を使用
- 図・表・数式の後に空行を置き、`{#fig:id}`・`{#tbl:id}`・`{#eq:id}`で安定IDを指定。`@fig:id`などの参照を番号付きリンクに変換し、プレビュー・HTML・PDFで同じ番号を表示
- 拡張構文の定義リストは`用語`の次行へ`: 説明`を書く。同じ用語に複数の説明を付けられ、2スペース字下げで説明を継続できる。プレビューは用語と説明を区別し、HTML・PDFでは`dl`として書き出す
- ハイライトは`<mark>文字</mark>`、上付きは`<sup>文字</sup>`、下付きは`<sub>文字</sub>`の限定HTMLを使用。Markdownメニュー・右クリック・コマンドパレットから選択文字列に適用できる。タグ内は改行とHTMLタグを含まないプレーンテキストに限る
- 55種類の絵文字ショートコードを同梱し、`:smile:`などをプレビュー・HTML・PDFで絵文字として表示。エディタで`:smi`まで入力してF5、またはMarkdownメニューの「絵文字ショートコードを補完」で候補を選べる。Unicode絵文字の直接入力はmacOS標準の文字ビューアを使う
- 単独行の`!audio[説明](path.mp3)`・`!video[説明](path.mp4)`はローカルファイルを標準の再生コントロールで表示。音声はMP3・M4A・AAC・WAV、動画はMP4・M4V・MOVに限定。HTML・PDFでは元ファイルへのリンクを出力し、ファイルがない場合は再生不可と表示する
- ツールバーの「スライド表示」で全画面発表。スライドモードでは空行で区切った単独行の`---`をページ境界にし、通常プレビューでは水平線のまま表示する。左右キーと画面下のボタンで移動でき、横長で1スライド1ページのPDFを書き出せる
- 保存済み文書ではツールバーの「Gitの差分と履歴」から、フォルダ全体の変更状態、文書の変更行、直近40件のコミットと過去版を確認できる。Gitがないフォルダでは理由を表示する
- ツールバーの「Gitのステージとコミット」で変更ファイルを選んでステージ・取り消し。ステージ済みファイルをすべて選択してメッセージを入力するとローカルコミットできる。競合ファイルは別欄から編集し、解消して保存した後にステージする
- 保存済み文書のツールバーからiCloudのダウンロード状態と競合版を確認。競合版・ディスク版・編集中の本文を比較して選択版をUndo可能な編集で採用し、保存完了後に競合解消を確定する
- macOSの「サービス」で他アプリの選択テキストをMarkdown書類として保存。ショートカットの「Markdown書類を保存」「MarkdownをHTMLに書き出す」では元テキスト／書類パス、保存先フォルダ、ファイル名を指定できる。同名ファイルは上書きしない
- [宣言的なJSON拡張](docs/extension-format.md)でプレビュー配色とスニペットを追加。設定から読込・削除でき、テーマの文字色はコントラストを検査する
- WordPressの投稿APIとGitHub Pages向けJekyllリポジトリへの下書き作成・公開。送信先と本文を確認してから実行し、アプリケーションパスワードまたはトークンをKeychainに保存できる
- 近くのmacOS利用者と暗号化された共同編集セッションを開始・参加。6桁の参加コード、接続中の参加者、選択範囲へのコメント・返信・解決を提供し、一時切断後は編集操作を合流する

## 実行

Xcode で `MKTownEditor.xcodeproj` を開き、`MKTownEditor` スキームを実行します。コマンドラインからは次の方法でも起動できます。

```sh
swift run MKTownEditor
```

Production（Release）ビルドで起動する場合は、次のスクリプトを使用します。

```sh
./start.sh
./start.sh rebuild # clean してからビルド・起動
```

通常起動では差分ビルドを行います。`rebuild` は Swift Package のビルド成果物（Debug を含む）を削除してから Release 構成でビルドします。

インストール済みのアプリ、または一度起動してURLスキームを登録したアプリへ、書類と行番号を渡せます。

```sh
swift Tools/mktown-open.swift --line 42 ~/notes/example.md
```

ファイルURLも指定できます。`mktowneditor://open?url=<パーセントエンコードしたfile URL>&line=42`を開いても同じ操作になります。行番号を省略すると書類だけを開きます。既に開いている書類はそのウインドウを使います。

## 数式の書き方

拡張Markdownでは、本文中の式を `$...$`、独立した式を `$$...$$` で囲みます。数式ブロックの前後に空行は不要です。

```markdown
本文中の式は $E = mc^2$ と書きます。
$$x^2 + y^2 = z^2$$
$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

プレビューとHTML／PDF出力で数式を表示します。通信は不要です。インライン数式の開始の `$` の直後と終了の `$` の直前には空白を置かず、文字として表示する `$` は `\$` と書いてください。コード内、未完成の式、SwiftMathが対応しないLaTeXコマンドは原文を表示します。MathJaxの全コマンドに対応するものではありません。基本Markdownでは数式記法を原文表示します。
