# MKTownEditor

MKTownEditor は、macOS の標準コンポーネントで構成した書類ベースの Markdown エディタです。CodiMD の編集・プレビュー体験を参考にしながら、ローカルファイルを扱うネイティブアプリとして設計しています。

## 主な機能

- `.md` / プレーンテキストファイルの読み込みと `.md` への保存
- 編集、左右分割、プレビューの3つの表示モード
- 見出し階層を表示するアウトラインサイドバー。項目を選ぶと編集位置とプレビューの見出しへ移動
- 編集カーソルが属する見出しをアウトライン内で強調表示
- 「移動」メニューの指定行へ移動で行番号を入力可能。範囲外は先頭または末尾の行へ補正
- 見出し名を絞り込むクイック検索から目的の見出しへ移動
- ナビゲーションの「戻る／進む」。アウトライン・指定行・見出し検索による移動を履歴で辿れる
- `#見出し`形式の文書内リンクから、重複名を区別して該当見出しへ移動
- 相対パスの Markdown リンクから別の書類を開き、`#見出し`指定があれば開いた書類の見出しへ移動
- リンク編集で現在の書類フォルダ内のファイル・フォルダを候補表示し、相対パスを補完
- `#`入力時に現在またはリンク先 Markdown 書類の見出しを補完し、既存の参照IDから参照形式リンクを挿入
- 文字列を選択して Web URL またはメール URL を貼り付けるとリンクに変換。コンテキストメニューからそのままの貼り付けも可能
- ツールバーのリンク診断でローカルファイル・画像・見出し・参照定義の欠落を一覧にし、原文の該当位置へ移動
- 分割表示で原文とプレビューをブロック単位で双方向スクロール同期
- プレビューの段落・見出し・コードなどのコンテキストメニューから、対応する原文範囲を選択して表示
- 編集とプレビューの表示倍率を別々に保存し、表示倍率メニューとショートカットから拡大・縮小・リセット
- Swift、JavaScript／TypeScript、Python、JSON、シェルのコードブロックを基本的な字句で色分け
- 編集画面で見出し、リスト、引用、コード、リンク、表の記号を色分け
- ソース編集の行番号ガター。長い行の折り返しは同じ行番号として表示
- Return でリスト・タスクリスト・引用を継続し、空項目では階層を終了
- Tab／Shift-Tab またはメニューでリスト項目と子ブロックのインデントを変更
- 括弧、バッククォート、強調記号の対を入力時に補完し、選択文字列も囲める
- 入力と同時に更新されるネイティブ Markdown プレビュー
- 編集中の構文解析・統計・色分けを同じ本文スナップショットから非同期更新
- GFM形式の表を列揃え付きで表示し、狭い画面では表ごとに横スクロール
- 行数と列数を指定してGFM表を挿入し、先頭の見出しセルを選択
- GFM形式のタスクリストを完了・未完了の状態付きで表示
- `~~取り消し線~~`、太字、斜体、インラインコードのプレビュー
- タスクリストの完了状態をカーソル行・複数選択行・プレビューのチェックボックスから切替可能
- 言語を選んでコードブロックを挿入可能。選択内のバッククォートより長いフェンスを使用
- 前後の段落に空行を確保して区切り線を挿入可能
- リンクの表示名・URL・タイトルをダイアログで挿入／編集可能
- 画像のURLまたはファイル、代替テキスト、タイトルをダイアログで指定して挿入可能
- 保存済み文書の相対パス画像をプレビューに縮小表示。見つからない画像は代替テキストを表示
- 画像ファイルを編集位置へドロップ可能。Markdownメニューで assets へのコピーまたは元ファイルへの相対参照を選択
- スクリーンショットなどのクリップボード画像を PNG として保存し、編集位置へ貼り付け可能
- `assets` への画像取り込み時は同一内容を再利用し、同名の別画像には連番を付与
- 文書内の参照定義を使うリンクと画像参照の表示
- 太字、斜体、取り消し線、リンク、コード、見出しレベル（H1〜H6・本文）、引用、箇条書き・番号付きリスト・タスクリストの書式コマンドをメニュー・ツールバー・右クリックから利用可能。太字・斜体・取り消し線・コードは再実行で解除可能
- macOS 標準の検索バー、Undo / Redo、スペルチェック
- 行数、単語数、文字数の表示
- VoiceOver 向けのラベルとシステム標準の外観・文字色
- プレビューの見出しレベル、表の列見出しと行位置、タスクの状態を読み上げ用に提示
- 設定画面で編集文字のフォント・サイズ・行間・余白を変更可能。文字サイズは「文字表示」メニューからも調整可能
- 設定画面で行の折り返し、タブ表示幅、リストとコードの字下げ幅を変更可能。折り返しを切ると横スクロールに切り替わる

## 動作環境

- macOS 14 以降
- Xcode 16 以降（Swift 6）

## 実行

Xcode で `MKTownEditor.xcodeproj` を開き、`MKTownEditor` スキームを実行します。コマンドラインからは次の方法でも起動できます。

```sh
swift run MKTownEditor
```

## テスト

swift test
