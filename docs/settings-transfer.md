# macOS版の設定のバックアップと移行

1. 「MKTownEditor」→「設定…」（⌘,）を開き、「一般」の「設定を書き出す…」を選ぶ。
2. 保存する項目を選び、JSONファイルの保存先を指定する。iCloud Driveを使っている場合は、保存先にiCloud Driveを選ぶと、同じアカウントの別のMacからそのファイルを開ける。
3. 設定を復元するMacで「設定」→「一般」→「設定を読み込む…」を選び、保存したファイルを開く。
4. 読み込み画面で現在の設定との差分を確認し、反映する項目を選ぶ。

書き出せるのは、一般、エディタ、プレビュー、配色、スニペット、用語辞書、ショートカット、書き出しプリセット、拡張の設定。読み込みは項目単位で適用する。たとえば「スニペット」を選ぶと、現在のスニペット一覧をファイルに含まれる一覧に置き換える。

書類・フォルダごとの設定、ブックマーク、フォルダへのアクセス権、Keychainの認証情報、Graphvizなどの外部ツールのパスは各Macで管理する。

## ファイル形式と検証

バックアップ用JSONには、種類を示す識別子と、選んだ項目ごとの設定を保存する。アプリ内部の[設定の保存形式](settings-backward-compatibility.md)とは別の形式で、読み込めるキーを項目ごとに定義する。新しい版がキーを追加しても、以前の版は自分が理解できる値だけを読み込む。ファイルに含まれない値は適用対象にならない。

`SettingsArchiveTests` で書き出しと読み込みの往復、選択項目だけの適用、未知のキーを含むファイル、壊れたファイルの扱いを検証する。
