# エディタの強調表示

[機能ガイドに戻る](features.md)

macOS版の「設定…」（⌘,）→「エディタ」→「強調表示」で次の3項目を個別にオンにできる。初期状態では3項目ともオフ。

- 「現在行を強調」は、カーソルがある論理行の背景を塗る。行が折り返されているときは、その行のすべての段を塗る。
- 「対応する括弧を強調」は、カーソルが括弧を1文字分またいだとき、対になる括弧を背景と枠で600ミリ秒表示する。`()`、`[]`、`{}`、`「」`、`『』`、`（）` などに対応する。コードブロックやインラインコード内の括弧は同じコード範囲の中で照合する。
- 「選択した単語の出現箇所を強調」は、単語全体を選ぶと、同じ単語の出現箇所を表示する。待ち時間は100〜2000ミリ秒から選べる。初期値は350ミリ秒。単語の区切りにはmacOSの判定を使い、大文字と小文字は区別する。

強調は画面に描画するため、本文・Undo履歴・コピーされる内容に影響しない。色はエディタの配色で決まり、カスタムテーマでも指定できる。[カスタムテーマの強調表示の色](preview-theme-authoring.md#エディタの強調表示の色)

## 検証

`EditorHighlightMatchingTests` で括弧の入れ子、コード範囲、対のない括弧、Unicodeの単語境界を検証する。`MarkdownEditorHighlightTests` では、折り返した現在行、末尾の空行、括弧の表示と消去、単語選択の待ち時間、コピーとUndoを確認する。

通常の入力中は括弧の探索を始めず、カーソルが括弧をまたいだときだけ別のタスクで探す。文書の解析が終わっていなければ、最新の解析結果を待つ。選択した単語の照合は、待ち時間が過ぎた後、再描画する範囲に絞って行う。

入力時間は、1万段落の文書で3項目をオンにした場合とオフにした場合を交互に計測する。挿入・削除の処理時間の中央値と95パーセンタイルが出力される。

```sh
MKTOWN_PERF=1 swift test --force-resolved-versions --filter MarkdownEditorHighlightTests/testLargeDocumentInputLatency
```

74万 UTF-16 単位の文書に対し、各条件で挿入・削除を150回ずつ計測した。オフ時は中央値97.3ミリ秒、95パーセンタイル143.2ミリ秒、オン時はそれぞれ81.2ミリ秒、116.0ミリ秒だった。計測範囲はAppKitの入力処理で、画面への描画時間は含まない。
