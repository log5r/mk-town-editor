# 入力中の構文ハイライト点滅

## 原因

`MarkdownTextEditor.Coordinator.refreshSyntax` は、本文と共有スナップショットが一致しない間、空の構文範囲をハイライターへ渡していた。ハイライターは全文の一時的な文字色を消去してから指定範囲を着色するため、入力のたびに見出しの青色が消え、非同期解析の完了後に復元されていた。

## 修正

共有解析を使う場合は、本文に一致する結果が届くまで構文色の更新を保留する。既存の色の範囲はTextKitが文字の挿入・削除に合わせて移動するため、古い解析結果を再適用せずに表示を保持できる。一致する結果が届いたら通常どおり更新し、見出し記号を削除した箇所などの不要な色を除去する。本文を同期解析するフォールバックは追加しない。

インライン表示の記号範囲も解析時の本文に対応している。解析待ちの間はこの更新も保留し、文字の挿入で位置がずれた古い範囲に色を上書きしない。日本語変換中の更新を避ける既存の判定は維持する。

同じ原因を調べるため、ハイライターの呼び出し元と一時的な文字色の消去箇所を検索した。共有解析待ちに空の範囲を渡す箇所はこのコーディネーターに限られていた。入力通知、選択変更、SwiftUIからの更新はいずれもこの処理を使う。

## 回帰テスト

`MarkdownSyntaxHighlighterTests` に、連続入力中の見出し色の保持、絵文字挿入後のUTF-16位置の移動、見出し記号削除後の色の除去を追加した。修正前のコードで追加テストが失敗し、解析待ちに青色が消えることを確認した。

`MarkdownInlineLivePresentationTests` には、解析待ちと古い解析結果の到着時に、位置がずれた見出し記号と本文の色を保持するテストを追加した。
