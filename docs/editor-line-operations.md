# 行の操作

macOS版の「編集」→「行の操作」から、行の昇順整列、逆順、重複削除、結合を実行できます。行の一部を選んだ場合も、その選択範囲が触れる行全体に適用します。選択範囲がなければ、書類全体が対象です。コマンドパレットからも実行でき、設定の「キーボード」でキーを割り当てられます。変更は⌘Zを1回押すと取り消せます。

重複行の削除では、内容が完全に一致する行のうち最初の行を残します。結合では、対象の行をつなぎ、境界の空白を1つにそろえます。たとえば、`日本語の` と `文章` を結合すると `日本語の文章` になります。空行を挟んでいる場合は空白を1つ入れます。

## 比較する部分を指定する

「条件を指定して行を並べ替え…」を選び、行全体、区切り文字で分けた列、正規表現の一致部分から比較対象を選びます。たとえば、`名称,件数` で始まる一覧を件数順にするには、区切り文字を `,`、列番号を `2` にし、「数値として比較」と「先頭行を固定」をオンにします。タブ区切りでは区切り文字に `\t` を入力します。

正規表現のキャプチャ番号に `0` を指定すると、最初の一致全体を使います。`1` 以降は、その一致のキャプチャグループを使います。サンプル行に表示された比較対象を確認してから「並べ替え」を押します。

「数値として比較」は、数字の並びを数値として扱います。たとえば `項目2` は `項目10` より前になります。「言語の規則に従う」は、現在の言語の並び順を使い、全角・半角を同じものとして扱います。大文字と小文字を区別するか、降順にするかも選べます。比較結果が同じ行は元の順序を保ちます。指定した列や一致部分がない行は末尾にまとまります。

## 検証

`EditorLineOperationTests`で行の範囲、改行コード、末尾に改行がない書類、日本語の結合、列・正規表現による比較を検査します。`EditorCommandTests`ではコマンドからの実行、ショートカットの保存、CRLFでの再保存を確認します。`MarkdownEditorModelTests`では、条件付きの並べ替えを1回のUndoで戻せることと、シートを開いた後に本文や選択範囲が変わった場合に適用を防げることを確認します。

正規表現の照合には時間がかかる場合があるため、プレビューと条件付きの並べ替えはバックグラウンドで計算します。シートを閉じたときは計算を取り消し、本文を書き換える直前にシートを開いたときの本文と選択範囲を照合します。
