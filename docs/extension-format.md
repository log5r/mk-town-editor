# 宣言的な拡張ファイル

設定の「拡張」からJSONファイルを読み込む。読み込んだ内容はアプリ設定に保存され、元のファイルが移動しても使える。同じ`id`のファイルを再読込すると置き換わる。削除するとその拡張のスニペットは消え、使用中のテーマはシステム配色へ戻る。

```json
{
  "schemaVersion": 1,
  "id": "example.notes",
  "name": "Notes",
  "theme": {
    "name": "Night",
    "background": "#000000",
    "body": "#FFFFFF",
    "heading": "#FFFFFF",
    "code": "#FFFFFF",
    "link": "#FFFFFF",
    "codeBackground": "#000000"
  },
  "snippets": [
    { "trigger": "sig", "template": "${1:名前}$0" }
  ]
}
```

`theme`または`snippets`の一方を省略できる。スニペットは既存のユーザー設定と同じTab展開・プレースホルダー規則を使う。テーマの文字色は背景およびコード背景に対して7:1以上のコントラスト比を必要とする。拡張は100KB以下、スニペットは100件以下とし、スクリプト・ネットワーク呼び出し・任意のCSS・実行可能コードは読み込まない。コードを実行する拡張機能のAPI、権限、障害隔離、互換性は別途設計が必要である。
