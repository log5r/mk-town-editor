# 空白と字下げ

macOS版の「設定」→「エディタ」で、字下げに使う文字と、行末の空白を削除する条件を選べます。最初はスペースを使い、自動検出と保存時の削除はオフです。ワークスペースの「フォルダの編集設定」では、項目ごとに値を指定できます。「継承」を選ぶと、最も近い親フォルダの設定か、アプリ全体の設定を使います。

## 字下げ

「書類の字下げを自動検出」をオンにすると、既存の字下げから文字と幅を推定します。判定できないときは、フォルダまたはアプリの設定を使います。

本文の一部を選んで Tab を押すと、選択範囲に触れる行の字下げが増えます。Shift+Tab で字下げを減らせます。スニペットの入力欄と表のセルでは、Tab は次の欄やセルに移動します。

既存の行を変換するには、本文を選び、「編集」→「空白と字下げ」から「字下げをスペースに変換」または「字下げをタブに変換」を選びます。変換では Markdown の構文を保つため、タブを CommonMark の4桁ごとのタブ位置で扱います。操作は1回の取り消しで戻せます。

## 行末の空白

「編集」→「空白と字下げ」→「行末の空白を削除」は、選択範囲内の行末空白を削除します。選択がなければ全文が対象です。Markdown の強制改行に使う行末空白とコードブロック内の空白は保持します。空白だけの行も整理するには「空白だけの行も対象にする」をオンにします。

「保存時に行末の空白を削除」をオンにすると、自動保存を含む書き込みで同じ規則を適用します。書類を編集画面でも整える場合は、手動コマンドを使ってください。名称未設定の書類にはアプリ設定を使い、保存先が決まった後はフォルダ設定を適用します。

## 検証

- 字下げのテストでは、スペース・タブの検出、選択行の編集・変換、Undoを検査します。
- 行末空白のテストでは、Markdown の改行、コードブロック、空白だけの行、選択範囲、混在する改行コードを検査します。
- 設定のテストでは、フォルダごとの継承と、項目が存在しない設定ファイルからの読み込みを検査します。
