# Unicode情報と不可視文字

macOS版では、見た目が似た文字やゼロ幅文字を選択して、コードポイントを調べられます。たとえば、検索語のスペースが `U+0020` でも、本文では `U+00A0`（ノーブレークスペース）が使われていることがあります。文字の情報を比較すると、検索に一致しない原因を確認できます。

## 選択した文字の情報を調べる

エディタで文字を選び、「編集」→「選択した文字のUnicode情報を表示」を選びます。文字ごとに、コードポイント、Unicode名、ブロック、一般カテゴリが並びます。結合文字や絵文字など、複数のコードポイントで構成される文字は、構成要素を1つずつ表示します。改行には保存時の形式を使います。たとえばCRLFの改行には `U+000D` と `U+000A` が並びます。

「コピー」を押すと、表示した情報をタブ区切りでコピーできます。VoiceOverでは各項目のラベルと値を読み上げます。読み取り専用の書類でも「編集」メニューから情報を表示できます。

## コードポイントで文字を挿入する

「編集」→「コードポイントから文字を挿入…」を選び、`U+3000` または `3000` の形式でコードポイントを1つ入力します。表示された文字とUnicode名を確認して「挿入」を押すと、選択範囲がその文字に置き換わります。選択がなければカーソル位置に挿入します。挿入は⌘Zで取り消せます。

編集できる書類では、Unicode情報の表示と文字の挿入をコマンドパレットから実行できます。設定の「ショートカット」でどちらにもキーを割り当てられます。

## 制御文字とゼロ幅文字の位置を表示する

設定の「エディタ」で「不可視文字を表示」をオンにすると、空白や改行に加えて制御文字とゼロ幅文字に目印が付きます。制御文字は橙色の記号、ゼロ幅文字は橙色の破線で表します。絵文字の連結や異体字の指定に使われるコードポイントは、文字を選択してUnicode情報から確認できます。

## 検証

- Unicode情報のテストでは、補助平面の文字、結合文字、異体字セレクタ、ゼロ幅接合子を含む絵文字、混在する改行を検査します。Unicodeのブロックと一般カテゴリはmacOS SDKのICUから取得します。
- macOSのアクセシビリティ検証では、`👩‍💻` を選択して「編集」からUnicode情報を開き、3つの構成要素すべてで項目名と値が読み上げ用のテキストに含まれることを確認します。
- 挿入のテストでは、入力形式、選択範囲の置換と取り消し、書類の変更後に古い挿入を拒むこと、指定した改行を保存することを検査します。
- 不可視文字のテストでは、目印の位置と本文の保持、絵文字や異体字を構成する文字の上に目印が重ならないことを検査します。
