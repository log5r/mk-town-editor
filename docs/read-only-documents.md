# 読み取り専用で書類を参照する

macOS版で開いている書類を保護するには、「編集」→「編集を禁止」を選びます。ファイルを選ぶ時点で保護するには、「ファイル」→「読み取り専用で開く…」を使います。ウインドウの下部に鍵のアイコンと「読み取り専用」が表示され、VoiceOverでも確認できます。ツールバーをカスタマイズして「読み取り専用」の切り替えを追加することもできます。

読み取り専用の間も、原文の選択・コピー・検索、行や見出しへの移動、別ファイルへの書き出しができます。本文の入力や貼り付け、置換、書式操作、プレビューのタスク切り替え、過去の版の復元は停止します。共同編集に参加中に切り替えると、そのウインドウのセッションは終了します。

編集を再開するには「編集」→「編集を許可」を選びます。状態はウインドウを閉じるまで有効です。書類とファイルのアクセス権はそのまま使います。

## 実装と検証

テキストビューの編集可否に加え、プレビューやシートから書類を変更する処理でもウインドウの状態を確認します。ウインドウをまたぐワークスペースのリンク更新は、対象の書類を読み取り専用で開いている場合に中止します。ディスクへの書き込み中に状態が変わったときは、反映直前の再検査で検出し、書き込みを取り消します。

`MarkdownEditorModelTests`で、読み取り専用での選択・コピー・検索と、入力・貼り付け・ドロップ・書式操作・置換・共同編集による変更の拒否を確認します。`EditorCompositionTests`で切り替え時に確定済みの本文が残ることを、`PreviewTaskUndoTargetTests`で切り替え前のUndo履歴が残ることを検証します。`WorkspaceOpenBufferTests`は、ファイル移動に伴うリンク更新の拒否とロールバックを検証します。書類を開く経路は、`EditorWorkspacePersistenceTests`、`ExternalDocumentOpenTests`、`Tools/test_mktown_open.py`で検証します。
